# Global_Exchange_E7
Repositorio para el desarrollo del proyecto Global Exchange
## Documentación del código

La documentación se genera automáticamente con [pdoc](https://pdoc.dev) a partir de los docstrings.

    docker compose run --rm web python generar_docs.py

También desde VS Code: `Ctrl+Shift+P` → *Run Task* → **Generar documentación (pdoc)**.

El resultado queda en `docs/api/index.html`.
